# Pane 布局

Claude Code 一侧 Pane 的等宽线框图，是各个视图实现的依据（#3）。Pane 用 Mods 的元素画在字符格子里（ADR-0002），所以这里画的就是字符。Codex 的界面不在这里。

图里的 Task、Session 和时间都是示例数据。

## 怎么读这些图

- 每张图是 Pane 正文区里的字符。引擎自己画的外框、关闭标记、同时开着几个 Pane 时的标签行不在图里。
- 停靠在侧边的图按 42 列画，输入框上方的按 96 列画。实际列数读 `Pane` 的 `bodyColumns`：宽了，一行左右两端之间的空白跟着变长；窄了，先截标题，截掉的地方以 `…` 结尾。
- 汉字和全角标点占 2 列，其余占 1 列，状态图形按 1 列算。图在终端和等宽编辑器里是对齐的；GitHub 网页上汉字不是正好两列，行的右端会参差。
- 图右边、Pane 边界之外的 `◀` 是标注，不画出来。`◀ 焦点` 表示这一行有焦点，整行的底色涂 `surface-raised`；紧跟着只标 `◀` 的行和它是同一个焦点行。`◀ 选中“任务”` 表示那一项加粗并带下划线。
- `e: 执行` 是普通按钮，`e` 是它的快捷键。`[ 我现在该做什么 ] n` 是主按钮，`n` 是它的快捷键。一屏只有一个主按钮。
- 每一节的第一张图画完整的一屏，其余的只画标签页的内容，上面四行不变。输入框上方的图总是四行都画。

### 图形

状态只用这九个图形，颜色是第二重提示，每个图形旁边都另有文字。

| 图形 | 含义 | 颜色 |
| --- | --- | --- |
| □ | 被阻塞 | `ink-faint` |
| ◇ | 可执行 | `progress` |
| ▶ | 进行中，本 Session | `progress` |
| ◐ | 进行中，其他 Session | `ink-muted` |
| ▲ | Orphaned | `warn` |
| ◈ | Pending Closeout | `unlock` |
| ◆ | 已关闭（界面上写“已解锁”） | `unlock` |
| ✕ | 读取失败 | `danger` |
| ✓ | 有 Acceptance Evidence | `pass` |

| `unlock` | `#f2c14e` | 已关闭、Pending Closeout、“收尾核对” |

### 元素

只用 Mods 的 `Box`、`Text`、`Button`、`Select`、`Link`、`Markdown`。`Input` 和 `Code` 没有用到。

| 图里的 | 元素 |
| --- | --- |
| 一行 | 横向的 `Box`，里面是 `Text` 和 `Button` |
| `e: 执行` | `<Button plain hotkey="e">` |
| `[ 我现在该做什么 ] n` | `<Button variant="primary" hotkey="n">` |
| 能获得焦点的一行（Task、树的节点、技能） | 不带 `hotkey` 的 `Button`，回车按下 |
| `┌─┐` 的框 | `<Box borderStyle="single">` |
| `┌╌┐` 的框 | `<Box borderStyle="dashed">` |
| `────` 分隔线 | `Text`，`─` 重复到 `bodyColumns` |
| 进度条 | 三段 `Text`：`━` 已关闭，`╍` 进行中，`─` 其余；全部关闭时整条 `━` 用 `unlock` |
| 树的连线 | `Text`：`├─` `└─` `│`，每一级 3 列 |
| `s: 切换` 打开的列表 | `Select` |
| 在 GitHub 打开 | `Link` |
| 描述、验收条件、技能原文、回答原文 | `Markdown` |

## 快捷键

`Button` 的 `hotkey` 只能是一个数字或一个小写字母，Pane 取得键盘之后才生效。同一屏上不出现两个用同一个键的按钮。

| 键 | 动作 | 出现在 |
| --- | --- | --- |
| `1` `2` `3` `4` | 切到 下一步、任务、地图、技能 | 标签页一行，一直在 |
| `r` | 重新读取 | 抬头，一直在 |
| `n` | 我现在该做什么；有了回答之后是“再问一次” | 停靠时在“下一步”里；输入框上方时在第二行右端 |
| `c` | 取消：持有中的请求，或接管确认 | “下一步”持有中；接管确认 |
| `f` | 筛选换到下一项：全部、可执行、进行中、阻塞、已完成 | “任务” |
| `e` | 执行（预填 Execute Prompt）；在技能上是预填技能调用 | 焦点行、返回栏、Recommendation |
| `o` | 钻进 Task 详情或技能原文；输入框上方的 Recommendation 上是看全文 | 焦点行 |
| `t` | 接管 | 被其他 Session 占用或 Orphaned 的焦点行；接管确认 |
| `x` | 释放 Occupancy | 本 Session 进行中或 Orphaned 的焦点行 |
| `k` | 收尾核对（预填提示词） | Pending Closeout 的 Spec |
| `m` | 打开这一行的 Spec 或 Map 的 Map View | “任务”里 Spec 和 Map 的焦点行 |
| `s` | 换 Map View 看的 Spec 或 Map | “地图”，项目里不止一个时 |
| `b` | 返回来的地方 | 返回栏 |
| 方向键、Tab | 移动焦点 | |
| 回车 | 按下焦点所在的按钮；在一行上等于 `o` | |

键盘怎么交给 Pane、怎么还给输入框，由引擎决定（这一版是 ctrl+x tab 和 Esc）。

## 两种位置

终端全屏且不少于 110 列时，Pane 停靠在侧边；否则显示在输入框上方。读 `Pane` 的 `placement`（`dock` 或 `inline`）决定用哪一套。

### 停靠在侧边

从上到下固定是：抬头两行、标签页一行、分隔线、当前标签页的内容。前四行在四个标签页里都不变。内容比 Pane 高时由引擎滚动。

```text
matt-deck · 5e1b7a02               r: 刷新  ◀ 项目（progress 加粗）、Session、刷新
本 Session ▶ #16 命令行           3 分钟前  ◀ 本 Session 正在执行的 Task；右端是数据有多新
1:下一步  2:任务  3:地图  4:技能            ◀ 标签页；选中的加粗带下划线
──────────────────────────────────────────
（当前标签页的内容，或钻进去的详情）
```

- 本 Session 没有 Occupancy 时第二行写 `本 Session 没有在执行 Task`。
- 新鲜度写相对时间。超过十分钟用 `warn` 色；读取失败时写 `读取失败`，用 `danger` 色。

### 输入框上方

宽而矮，四行：

```text
matt-deck · 5e1b7a02  ▶ #16   ◇ 1 可执行  ▶ 3 进行中  □ 11 阻塞  ◆ 2/17        3 分钟前  r: 刷新  ◀ 第一行
1:下一步  2:任务  3:地图  4:技能                                            [ 我现在该做什么 ] n  ◀ 第二行
（第三行：焦点所在的那一项，右端是它的动作）
（第四行：排在它后面的几项，或一句说明）
```

- 第一行把抬头和计数并成一行：项目、Session、本 Session 正在执行的 Task、可执行、进行中、阻塞、已关闭数比总数、新鲜度、刷新。列数不够时依次省掉：计数后面的字（只留图形和数字）、Session 标识、新鲜度。
- 第二行是标签页，右端是主按钮。推荐请求在持有中、已发出、运行中时，主按钮换成阶段条，四个标签页里都看得到。
- 后两行是当前标签页的内容：第三行是焦点所在的那一项，第四行是排在它后面的几项。方向键移动焦点，两行跟着换。
- “下一步”“任务”“技能”固定四行，不足的补空行，Pane 的高度不随状态变。
- “地图”、Task 详情、技能原文、Recommendation 全文不守四行：前两行不变，下面照停靠时的画法往下排，Pane 长到引擎给的高度，再多由引擎滚动。按 `b` 或切到别的标签页之后回到四行。
- 这里不画带边框的提示。提示占后两行：第三行是标题和动作，第四行是说明。

## 进入和返回

- Pane 取得键盘时，焦点落在当前标签页的第一个可执行 Task 上；没有可执行的，落在第一行。
- 在一行上按回车或 `o`，当前标签页的内容换成详情，抬头和标签页不动。不开弹窗。
- 详情顶上是返回栏：`b: 返回`、来路、这一项的动作。按 `b` 回到来的地方，焦点回到原来那一行，筛选不变。
- 在详情里对“被阻塞”下面的一行按回车，继续钻进那个 Task，来路跟着变长；`b` 一次退一层。
- 在详情里按 `1` 到 `4` 直接切走。再回到这个标签页时看到的是列表。
- 动作只预填：`e` 把 Execute Prompt 或技能调用放进输入框，`k` 把收尾核对的提示词放进输入框，都不发送。只有 `n` 会自己发出请求。

- 焦点行展开第二行，缩进 2 列：左边是 Task Source 里的 triage 标签，右端是这一行的动作。同一时间只有一行展开。

### Task 详情

从“地图”里钻进一个被阻塞的 Task。被阻塞的 Task 没有动作，返回栏右端是空的：

